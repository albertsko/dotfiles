# Pragmatic Code

Apply the relevant programming principles to keep code correct and easy to change.

## Read the relevant reference

- For implementation, code review, or local refactoring, read [tactical programming](references/tactical-programming.md).
- For software design, component boundaries, data flow, configuration, or concurrency decisions, read [strategic programming](references/strategic-programming.md).

Read both when the task includes design and implementation. Load only the reference needed for a task confined to one concern.
