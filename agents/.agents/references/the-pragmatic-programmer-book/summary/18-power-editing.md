## 18. Power Editing

Editor fluency makes text manipulation, the raw material of programming, feel instinctive, shortening the path from thought to working text and improving flow as well as saving time. Fluency does not require knowing every command or using one editor for every task; it means mastering the features that make work easier in each editor you use, including keyboard-driven navigation and selection at textual and syntactic levels, reindentation, block comments, undo and redo, panels, line jumps, sorting, string and regular-expression searches, multiple cursors, and access to compilation errors and tests. Build that fluency by noticing repetitive actions, finding better commands, and repeating them until they become muscle memory. Extend the editor when built-in behavior falls short: install suitable integrations, automate recurring work with its extension language, and create and publish an extension when no existing one meets the need.

### The Pragmatic Approach

- Learn keyboard commands for moving, selecting, and deleting by character, word, line, paragraph, and code structure.
- Practice useful commands many times each day until they become automatic.
- Replace repeated manual editing with a command or small automation.
- Reindent code, toggle block comments, undo and redo, split and navigate panels, jump to lines, sort selections, search with strings and regular expressions, repeat searches, and edit with multiple cursors without reaching for a pointing device.
- Display compilation errors and run project tests from the editor.
- Disable key autorepeat and work without a mouse or trackpad for a week to expose gaps in keyboard fluency.
- Keep a list of missing integrations, search for extensions, and learn the editor's extension language.
- Build and publish an extension when no available tool solves a recurring need.
