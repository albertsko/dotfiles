## 21. Text Manipulation

Text manipulation languages provide a powerful, general-purpose way to transform data, automate work, and prototype ideas when specialized tools cannot handle the job. Shells combined with tools such as `awk` and `sed`, along with structured languages such as Python and Ruby, can produce useful utilities in far less time and code than conventional approaches, making quick experiments and project automation practical. They can build documents, extract and highlight tested code without duplication, update websites, format equations, generate indexes, convert file formats, and find or rename identifiers. Their speed and versatility reward mastery, especially when information is kept as plain text, but mistakes can damage many files at once.

### The Pragmatic Approach

- Learn one text manipulation language well.
- Use text manipulation to test ideas quickly and automate recurring project work.
- Keep information in plain text when practical so scripts can process it easily.
- Extract generated content from authoritative files instead of copying and maintaining duplicates.
- Write small utilities for bulk conversions, searches, reports, and controlled edits.
- Back up original files and inspect results before accepting automated changes.
