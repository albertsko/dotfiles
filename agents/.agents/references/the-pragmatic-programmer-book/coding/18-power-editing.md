## 18. Power Editing

Editor fluency lets software engineers translate ideas into code without interrupting their reasoning to manage editing mechanics. Fluency means navigating text and syntax precisely, applying common transformations with single commands, searching and editing repeated patterns, managing multiple views, and running project feedback from the keyboard. Build fluency incrementally: notice repetitive work, learn the command or extension that removes it, and practice until the action becomes automatic.

### The Pragmatic Approach

- Observe each editing session and record repetitive actions, mouse-dependent steps, and apparent limitations; treat each one as a prompt to find a faster command or extension.
- Navigate and select by character, word, line, paragraph, and code structure such as matching delimiters, functions, and modules.
- Apply structural edits with dedicated commands: reindent changed code, comment or uncomment blocks, sort selected lines, and undo or redo changes.
- Navigate an entire project without leaving the keyboard: split the editor into panels, move between them, and jump directly to a line number.
- Search for literal strings and regular expressions, repeat previous searches, and use multiple cursors to update every selected or matching occurrence in parallel.
- Display compilation errors and run project tests inside the editor so feedback stays beside the code being changed.
- Practice one useful command many times each day for about a week; temporarily disable key autorepeat or avoid the mouse to expose gaps and build muscle memory.
- Learn every editor you use well enough to perform frequent tasks without thinking about mechanics; focus on useful commands rather than memorizing the entire command set.
- Search for an extension when the editor lacks a needed capability, then learn the extension language and automate recurring work with a small script when no suitable extension exists.
- Build and publish a full extension when a recurring need justifies it and the solution could help other engineers.
