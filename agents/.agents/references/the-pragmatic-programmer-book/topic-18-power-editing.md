## Topic 18: Power Editing

Text is the primary raw material of programming. Developers must manipulate text effortlessly, using their editors as extensions of their hands. Achieving fluency in your editors removes mechanical friction between thinking code and editing buffers. Removing mechanical friction frees cognitive capacity, allowing thoughts to flow directly into code. True fluency requires performing text navigation, code refactoring, multi-cursor editing, window layout management, and test execution strictly through keyboard commands without relying on a mouse or trackpad.

### The Pragmatic Approach

- **Achieve Editor Fluency**: Master keyboard shortcuts for moving by syntactic units, editing with multiple cursors, running tests, and managing split windows.
- **Identify Repetitive Tasks**: Monitor your editing habits continuously. Look for automated commands or shortcuts whenever you perform a manual, repetitive edit.
- **Build Muscle Memory**: Practice newly discovered shortcuts through daily repetition until keyboard execution becomes an instinctive habit.
- **Extend Editor Functionality**: Install extensions to overcome editor limitations, or write custom scripts in the extension language to automate repetitive project tasks.

### Common Mistakes

- **Relying on the Mouse**: Reaching for the mouse or trackpad for standard navigation and selection interrupts editing focus and slows down development.
- **Ignoring Advanced Features**: Remaining limited to basic text editing instead of adopting multi-cursor edits, regular expression searches, and code formatting commands.
- **Memorizing Commands in Bulk**: Trying to learn an editor's entire manual at once instead of incrementally practicing shortcuts that solve immediate friction.
- **Tolerating Tool Friction**: Manually executing repetitive sequences instead of searching for existing extensions or writing custom automation scripts.
